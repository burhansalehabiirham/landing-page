Panduan Laporan & Export Excel

Data yang muncul di laporan tersimpan permanen dalam format JSON di browser Anda.

Langkah-langkah Impor JSON ke Excel:
Anda dapat membuka file backup (.json) menggunakan Excel modern yang mendukung Power Query.
  1. Klik tombol "Backup Data (JSON)" untuk mengunduh database.
  2. Buka Microsoft Excel > Tab Data.
  3. Klik Get Data > From File > From JSON.
  4. Pilih file backup yang diunduh tadi.
  5. Lalu klik Load untuk melihat data di dalam Excel.
